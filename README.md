# ZeeML Global CGPA, GPA, ECTS & Percentage Grading Equivalency Dataset (`v1.0`)

This dataset provides 510 credit-weighted conversion records mapping 10.0-scale Cumulative Grade Point Averages (CGPA) across six university and regulatory conversion equations (`CBSE_UGC_9_5`, `DECIMAL_10_0`, `AICTE_VTU_SHIFT`, `MUMBAI_7_1_OFFSET`, `ECTS_BOLOGNA_NORM`, and `WES_APPROX_NORM`) to equivalent percentage scores, 4.0 US linear and tier GPAs, 5.0 GPA, German Modified Bavarian formula values, European ECTS letter bands, and UK Honours classifications.
